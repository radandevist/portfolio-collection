This is the first post on my new portfolio site. I built it with React Router v7, TypeScript, and TailwindCSS.

## Why I Built This

I wanted a minimal space to share projects and occasionally write about things I'm learning. No analytics, no tracking, no clutter—just content.

> The best code is no code at all. Every line of code you write is a line that needs to be maintained, debugged, and understood by others.

## What to Expect

I'll write about:

- Technical deep-dives into problems I've solved
- Tools and workflows that improve my productivity
- Lessons learned from building software

## Code Examples

Here's a simple TypeScript function:

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```

And here's the same thing in JavaScript:

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```

A C# example:

```csharp
using System;

public class Program
{
    public static void Main()
    {
        Console.WriteLine(Greet("World"));
    }

    public static string Greet(string name)
    {
        return $"Hello, {name}!";
    }
}
```

And some bash commands:

```bash
# Navigate to project directory
cd my-project

# Install dependencies
npm install

# Start the development server
npm run dev
```

You can also use `inline code` for small snippets like variable names or commands.
